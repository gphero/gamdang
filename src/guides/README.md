# 글 쓰는 법

이 폴더에 `.md` 파일을 하나 만들면 글 하나가 됩니다. 코드는 건드리지
않습니다. **파일 이름이 그대로 주소**가 됩니다.

    src/guides/water-bill.md  →  /guide/water-bill

GitHub 웹에서 바로 써도 됩니다. 이 폴더에서 **Add file → Create new
file**을 누르고 쓴 뒤 커밋하면, 몇 분 뒤 사이트에 올라갑니다.

## 파일 맨 위

```
---
title: 수도요금 고지서 읽는 법
summary: 목록에 나오는 한 줄 설명입니다.
stage: 1
order: 20
---

본문을 여기서부터 씁니다.
```

| 항목 | 뜻 |
| --- | --- |
| `title` | 글 제목. 꼭 적습니다 |
| `summary` | 목록 카드에 나오는 한 줄 |
| `stage` | 어느 단계에 넣을지. 아래 참고 |
| `order` | 같은 단계 안에서의 순서. 작은 값이 먼저 |
| `draft` | `true` 면 사이트에 나오지 않습니다. 쓰는 중일 때 |

`stage` 를 빠뜨리면 '그 밖에' 묶음으로 갑니다. 단계는 `../guides.js`
맨 위의 `STAGES` 에 있고, 새 묶음이 필요할 때만 거기를 고칩니다.

| stage | 묶음 |
| --- | --- |
| 1 | 내가 얼마를 쓰는지 안다 |
| 2 | 무너지지 않을 선을 만든다 |
| 3 | 남는 돈을 굴린다 |
| 4 | 지치지 않게 유지한다 |
| 5 | 큰 지출을 감당한다 |

## 본문에서 쓸 수 있는 것

아주 작은 마크다운만 처리합니다. 아래가 전부입니다.

```
## 소제목

문단은 그냥 씁니다.

- 목록
- 목록

| 항목 | 값 |
| 가 | 1 |
| 나 | 2 |

> 강조 상자. 글 끝맺음이나 단서에 씁니다.

**굵게** 와 [링크](https://example.com) 와 [내부 링크](/guide/food-label)
```

주의할 점이 몇 가지 있습니다.

- **`###` 는 없습니다.** 소제목은 `##` 한 단계뿐입니다
- **표는 머리글 구분선(`|---|`)을 쓰지 않습니다.** 첫 줄이 머리글입니다
- **굵게 안에 링크를 넣지 마세요.** `**[글자](주소)**` 는 링크가 깨집니다
- `*기울임*`, 이미지, 코드블록은 처리하지 않습니다

## 쓸 때

- 숫자나 제도는 바뀝니다. 금액을 적기보다 **방법**을 적는 쪽이 오래갑니다
- 제도를 적을 때는 공식 사이트를 링크하고, 조건은 확인하라고 적습니다
- 건강·식습관처럼 사람마다 다른 얘기는 **해당되지 않는 경우**를 같이 적습니다
